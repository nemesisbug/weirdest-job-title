## The entry

> Professional Apology Writer for Cats

One line, 36 characters. A job title that reads like a real posting —
"Professional ... Writer" is a shape every hiring page knows — until the
client turns out to be a cat. Someone has to draft the apology for the
knocked-over vase, the 3 a.m. zoomies, the hairball on the good rug, and
the cat is never, ever going to say sorry first. The twist lands on the
first read, and you can picture the person doing it: a desk, a laptop,
a very unimpressed cat staring at the draft — and rejecting every version.

## How it works

`main.py` (Python 3.13, standard library only) writes the title to
`/output/entry.txt` and checks it against the 1–60 character gate first.
No network, no input files, no secrets.

Run it:

```sh
python3 main.py
```
